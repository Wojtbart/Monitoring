2. RESTART / STATUS BACKENDU (systemd, gunicorn)
----------------------------------------------------------------------

  sudo systemctl restart monitoring-backend
  sudo systemctl status monitoring-backend
  sudo journalctl -u monitoring-backend -f          # logi na żywo (Ctrl+C aby wyjść)
  sudo systemctl daemon-reload                       # po EDYCJI pliku .service

3. NGINX (frontend statyczny)
----------------------------------------------------------------------

  sudo nano /etc/nginx/sites-available/monitoring    # edycja configu
  sudo nginx -t                                       # sprawdź składnię PRZED reloadem
  sudo systemctl reload nginx
  sudo tail -f /var/log/nginx/error.log               # logi błędów na żywo

6. GPIO — weryfikacja pinów fizycznym testem (NIE ufaj samemu odczytowi)
----------------------------------------------------------------------

  pinctrl get 6            # np. czujnik drzwi — otwórz/zamknij drzwi i porównaj
  pinctrl get 17            # DHT22
  pinctrl get 22            # PIR ruchu — pomachaj ręką
  pinctrl get 23            # woda — zwilż płytkę
  pinctrl get 24            # płomień/IR — obróć potencjometr na płytce
  pinctrl get 27            # gaz/dym MQ-2 — obróć potencjometr na płytce

Szybki test DHT22 bez uruchamiania całej apki:
  python3 -c "
import board, adafruit_dht, time
sensor = adafruit_dht.DHT22(board.D17)
for _ in range(6):
    try:
        print('temp:', sensor.temperature, 'hum:', sensor.humidity)
    except RuntimeError as e:
        print('retry:', e)
    time.sleep(2)
"

Szybki test modułu SIM800L (GSM):
  python3 -c "
import serial, time
s = serial.Serial('/dev/serial0', 9600, timeout=2)
time.sleep(1)
s.write(b'AT\r\n')
time.sleep(1)
print(s.read(s.in_waiting or 1))
"
# powinno zwrócić coś zawierające OK

9. TYPOWE PROBLEMY — SKRÓT (pełen opis root-cause w docs/raspberry-pi-deployment.md)
----------------------------------------------------------------------

- 500 z nginx                    -> permission denied w error.log -> chmod o+x na
                                     łańcuchu katalogów + chmod -R o+rX na dist
- SIGSEGV workera przy nagrywaniu -> picamera2/libcamera nie jest thread-safe,
                                     wymaga -k gthread + lock w Camera (już naprawione w kodzie)
- Video nie odtwarza się w przeglądarce -> kodek mpeg4 zamiast h264 -> ffmpeg
                                     transkoduje automatycznie po nagraniu (już w kodzie)
- Po npm run build strona nie ładuje JS
  (Failed to load module script, MIME text/html) -> przeglądarka ma w cache
  stary index.html wskazujący na nieistniejący już plik JS (hash się zmienia
  przy każdym buildzie) -> hard refresh / incognito; na stałe: nginx
  "location = /index.html { add_header Cache-Control "no-cache"; }"
- real-time-data zwraca 0.0 mimo ustawionego <X>_BACKEND w .env -> stałe
  modułowe w sensors.py czytane PRZED load_dotenv() w app.py -> backend env
  musi być czytany w Sensor.__init__, nie na poziomie modułu (już naprawione)
